# Fase 0 - Criterios de Aceptacion

## Checklist bloqueante

## A. Convenciones cientificas

1. Firma metrica definida y documentada.
2. Sistema de unidades y constantes congelado.
3. Convenciones de marcos y transformaciones definidas.
4. Convenciones de tolerancias numericas definidas.

## B. Supuestos y restricciones

1. Supuestos subluminales y superluminales documentados.
2. Restricciones fisicas duras y blandas separadas.
3. Criterios de parada de simulacion definidos.
4. Politica de incertidumbre y calidad de datos definida.

## C. Contratos

1. Contrato Nucleo -> Simulador definido.
2. Contrato Simulador -> PSO definido.
3. Contrato Datos -> Riesgo definido.
4. Errores tipados por contrato definidos.

## D. Implementacion base

1. Tipos de contrato en codigo Python disponibles.
2. Interfaces abstractas/protocolos disponibles.
3. Configuracion cientifica serializable versionada.
4. Exportes de API de contratos centralizados.

## Criterio final de aprobacion

La Fase 0 se considera aprobada solo si todos los items A-D estan completos y trazables en repositorio.
